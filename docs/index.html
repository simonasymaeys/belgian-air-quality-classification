UNDER THE HOOD

A real model.
A retrospective experiment.

This interface replays the frozen logistic model’s saved test predictions. It does not run a new forecast or fetch current readings.

How it was evaluated

Trained on 2022–2023. Settings selected on 2024. Original final evaluation on 2025. Imputation and scaling were fitted on training data only.

What the headline leaves out

Across all stations, recall was 90.1% and precision 27.4%. The model raised 7,641 false alarms. Performance varied by season and station.

Before any practical use

Live-data timing, calibrated scores, an agreed false-alarm tolerance, human review and testing on a fresh period would be needed. This is an educational prototype, not an official warning service.
